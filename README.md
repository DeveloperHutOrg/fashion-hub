# FASHION HUB — Modern Luxury Fashion E-Commerce

A premium, modern fashion e-commerce platform built with Next.js, TypeScript, and Tailwind CSS. Inspired by luxury fashion editorial publications and minimalist design houses.

![Fashion Hub](https://images.unsplash.com/photo-1490481651871-ab68de25d43d?q=80&w=2070&auto=format&fit=crop)

## ✨ Features

- **Editorial Homepage**:
  - Fullscreen editorial hero section with "DEFINE YOUR STYLE." and dual CTAs.
  - "NEW ARRIVALS" drop section showcasing seasonal hero pieces.
  - "THE NEW CLASSIC" split-screen capsule feature.
  - "SHOP BY CATEGORY" visual universe tiles (Women, Men, Accessories).
  - Magazine-style "FASHION, YOUR WAY" editorial grid with asymmetry and quotes.
  - "TRENDING NOW" horizontally scrollable carousel with desktop controls and mobile touch swipe.
  - Promotional seasonal archive private sale banner (Up to 40% Off).
  - Minimal luxury newsletter subscription ("STAY IN THE KNOW").

- **Product Details (`/product/[id]`)**:
  - Multi-view high-res interactive image gallery with magnifying hover zoom.
  - Swatch-based color selector and size selection.
  - Interactive Size Guide modal with CM / IN unit conversion.
  - Quantity adjuster with Add to Bag and 1-tap Buy Now actions.
  - Wishlist toggle and accordion sections for shipping, returns, and care.
  - Mobile sticky purchase bar for streamlined purchasing.
  - Curated complementary product recommendations ("You May Also Admire").

- **Catalog & Shop All (`/shop`)**:
  - Dynamic category pills (All, Women, Men, Accessories, Sale Archive).
  - Expandable filter tray for sizes, colors, and keywords.
  - Sort by Featured, New Arrivals, Price (Low/High), and Rating.
  - Responsive 4-column desktop and 2-column mobile layout.

- **Shopping Bag & Wishlist Drawers**:
  - Slide-out cart drawer with dynamic free shipping progress bar.
  - Cart item management (quantity adjustments, instant removal).
  - Saved items wishlist drawer with 1-click "Move to Bag".
  - Live keyword search modal with trending search shortcuts.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Icons**: [Lucide React](https://lucide.dev)
- **Typography**: Google Fonts (`Playfair Display` + `Plus Jakarta Sans`)
- **Deployment**: [Vercel](https://vercel.com)

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

To create an optimized production build:

```bash
npm run build
npm run start
```

## 🚢 Deploying to Vercel

1. Push this repository to GitHub: `https://github.com/DeveloperHutOrg/fashion-hub.git`
2. Import the project in the [Vercel Dashboard](https://vercel.com/new).
3. Vercel automatically detects Next.js framework settings. Click **Deploy**.
